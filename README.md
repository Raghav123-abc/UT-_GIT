# TVM Project Repository

## Structure

```
Documentation/
├── Instructions/          Repository rules (Claude_Project_Rules.md)
├── Knowledge_Base/        Reference notes and how-tos
├── Requirements/          Requirements, by date
├── Change_Records/        Metadata changes with before/after values, by date
├── Conflicts/             Conflict logs, by date
├── Deployment/            Deployment notes, by date
└── Technical_Documents/   Apex, Flows, Objects, Fields, Validation_Rules,
                           Omni_Channel, Amazon_Connect, Integrations,
                           Reports, Dashboards
Salesforce_Metadata/       Salesforce metadata source
```
